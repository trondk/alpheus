# Documentation

The documentation pages of [alpheus-dev.org](https://alpheus-dev.org/docs/).
They live here, next to the code, so a change to the code and its
documentation goes in the same pull request (WWW-22). The website's own
repository fetches this folder when it builds; this README is left out.

The pages are Markdown for Hugo: front matter at the top, and shortcodes
such as `{{< repolink "path" >}}` (a link into this repository) and
`{{% planned %}}` (a note on what is not released yet), which only the
website renders.

`cli.md` is generated by `make generate` from `internal/cli`; do not edit
it by hand.
